下游报表里出现了本该被删掉的字段，血缘图却显示这条链路早就断了：血缘按上游到下游方向传播；一个字段可来自多个上游；删除上游必须影响全部下游；环路必须检测并拒绝；字段级而非表级传播；同一字段多次传播只记一次；批量构建各图独立。不变量：血缘关系传递闭包正确；环路检测不改变已有边。

## 图模型

字段是图里的节点，血缘是有方向的边，方向从上游字段指向下游字段。同一个字段可以同时出现在多条边里，节点集合和边列表共同描述一张图。所有传播与查询都以字段为单位，不按表聚合。

## 契约

删除一个上游字段时，所有沿有向边可达的下游字段都受影响。环路检测是只读操作，不得改变已有边。合并两张图时，节点与边都取并集。批量构建返回的图之间不共享可变状态。校验只报告图自身的结构问题，不修改图。
